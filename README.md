# Moribund: web demo

A playable browser demo of **Moribund**, a gothic isometric action RPG built in Godot 4 by Mohammad Adil Abdulrashid.
It covers the village of Ashwick and the Weeping Graves.

Play it at **https://eng-adil.github.io/moribund-demo/** (desktop browser recommended).
